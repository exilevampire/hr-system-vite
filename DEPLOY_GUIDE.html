2สร้างฐานข้อมูล

เปิด MariaDB / MySQL แล้วรันคำสั่งต่อไปนี้:

-- สร้างฐานข้อมูล
CREATE DATABASE hr_integrity_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

-- สร้าง user สำหรับระบบ (ไม่ควรใช้ root)
CREATE USER 'hruser'@'localhost' IDENTIFIED BY 'รหัสผ่านที่แข็งแกร่ง';
GRANT ALL PRIVILEGES ON hr_integrity_db.* TO 'hruser'@'localhost';
FLUSH PRIVILEGES;
⚠️ ข้อควรระวัง ไม่ควรใช้ user root สำหรับ connection ของแอปพลิเคชัน ให้สร้าง user แยกต่างหากพร้อมกำหนดสิทธิ์เฉพาะฐานข้อมูล hr_integrity_db เท่านั้น

3ติดตั้งโปรเจกต์

git clone https://git.redcross.or.th/pornpetch.n/hr-system.git
cd hr-system
npm install
ℹ️ หมายเหตุ npm install จะรัน prisma generate อัตโนมัติผ่าน postinstall hook — ไม่ต้องรันแยก

4ตั้งค่า Environment Variables

สร้างไฟล์ .env ในโฟลเดอร์โปรเจกต์:

# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env

แก้ไขไฟล์ .env ให้ตรงกับเซิร์ฟเวอร์:

DATABASE_URL="mysql://hruser:รหัสผ่าน@localhost:3306/hr_integrity_db"
JWT_SECRET="ค่าสุ่ม-ยาว-อย่างน้อย-32-ตัวอักษร"
PORT=3001
NODE_ENV=production

วิธีสร้าง JWT_SECRET แบบสุ่ม

node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
🚨 ข้อห้ามเด็ดขาด ห้าม commit ไฟล์ .env ขึ้น Git — ไฟล์นี้ถูก .gitignore ไว้แล้ว
ต้องตั้ง NODE_ENV=production บน production server เสมอ
ห้ามใช้ JWT_SECRET เดียวกับ development environment

5สร้างตารางฐานข้อมูล

รันคำสั่งนี้เพื่อสร้างตารางทั้งหมดตาม schema:

npx prisma db push
ℹ️ หมายเหตุ คำสั่งนี้รันได้ครั้งเดียวตอนติดตั้งครั้งแรก หากมีการแก้ไข schema ในภายหลังให้รัน npx prisma migrate dev แทน

8ตั้งค่า PM2 (Process Manager — แนะนำ)

PM2 ทำให้ระบบรันค้างไว้และ restart อัตโนมัติเมื่อเซิร์ฟเวอร์ reboot:

# ติดตั้ง PM2 (ครั้งเดียว)
npm install -g pm2

# เริ่มต้นระบบด้วย PM2
pm2 start dist/server/index.js --name "hr-system"

# ตั้งค่าให้ auto-start เมื่อ reboot
pm2 startup
pm2 save
คำสั่ง PM2ความหมาย
pm2 statusดูสถานะ process ทั้งหมด
pm2 logs hr-systemดู log แบบ real-time
pm2 restart hr-systemrestart ระบบ
pm2 stop hr-systemหยุดระบบ
pm2 reload hr-systemreload แบบ zero-downtime

9ตั้งค่า Nginx (ถ้ามี Domain)

ถ้าต้องการให้เข้าถึงผ่าน domain name หรือ HTTPS ให้ตั้งค่า Nginx เป็น reverse proxy:

server {
    listen 80;
    server_name hr.redcross.or.th;  # เปลี่ยนเป็น domain จริง

    location / {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # จำกัดขนาด upload (สำหรับ Excel import)
    client_max_body_size 10M;
}
ℹ️ HTTPS แนะนำให้ใช้ Let's Encrypt + Certbot เพื่อเปิดใช้ HTTPS ฟรี:
sudo certbot --nginx -d hr.redcross.or.th

10Security Checklist ก่อนเปิดใช้งาน

  • ตั้งค่า NODE_ENV=production ในไฟล์ .env
  • สุ่ม JWT_SECRET ด้วย crypto.randomBytes(48) — ไม่ใช้ค่า default
  • เปลี่ยนรหัสผ่าน default users ทั้งสามบัญชีหลัง seed
  • ใช้ database user แยก — ไม่ใช้ root
  • ไฟล์ .env ไม่ถูก commit ขึ้น Git
  • Firewall เปิดเฉพาะ port ที่จำเป็น (80, 443, 22)
  • ตั้งค่า HTTPS ถ้ามี domain (ป้องกัน JWT token โดน intercept)
  • ทดสอบ login และ 2FA ทำงานได้ถูกต้อง
  • ทดสอบ Excel import/export ทำงานได้
  • ตั้งค่า backup ฐานข้อมูลอัตโนมัติ (mysqldump + cron job)

11สิทธิ์การใช้งาน (Roles)

Roleสิทธิ์การใช้งาน
SUPER_ADMIN เข้าถึงทุกฟังก์ชัน — เพิ่ม/แก้ไข/ลบข้อมูล, จัดการ User, ดู Audit Log
HR_ADMIN เพิ่ม/แก้ไขข้อมูลพนักงาน, นำเข้า Excel, ดู Audit Log (ไม่สามารถลบ/จัดการ User ได้)
VIEWER ดูข้อมูลและค้นหาเท่านั้น — ไม่สามารถแก้ไขได้
